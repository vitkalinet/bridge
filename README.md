# 🌉 Культурный мост: традиции и языки малых народов России

**Цифровой информационно-просветительский ресурс**, посвящённый малым коренным народам России.

> *«Каждый народ — отдельный мир со своим голосом»*

Проект не перечисляет сухие демографические данные, а через **краткие, эмоционально насыщенные и визуально закреплённые факты** показывает культурную ценность каждого этноса, его уникальные адаптации к природной и социальной среде.

**Форма взаимодействия:** карточки, раскрывающиеся по нажатию → эффект личного открытия.

---

## 📋 Представленные народы

1. **[Кереки](http://localhost:3000/kereki)** (Чукотка) — 106 чел. (2021)
   - Самоназвание: *ацэмэлыт* — «люди этого берега»
   - Изобрели упряжку «цугом» — паровозиком
   - Керекский язык — «спящий»

2. **[Чамалалы](http://localhost:3000/chamalaly)** (Дагестан, Чечня) — 452 чел. (2021)
   - Самоназвание: *чамалал* — «горные люди»
   - Трёхэтажные каменные дома >1000 лет
   - Прозвище: «горные джинны»

3. **[Водь](http://localhost:3000/vod)** (Ленинградская область) — 477 чел. (2021)
   - Самоназвание: *vaďďa* — «человек земли»
   - Копорский чай — торговая война с Англией
   - 10–15 носителей языка, все старше 75 лет

4. **[Тазы](http://localhost:3000/tazy)** (Приморский край) — 1106 чел. (2021)
   - Самоназвание: *таза* — «чистый, свежий»
   - Халаты из рыбьей кожи
   - Синкретичный народ: удэгейцы + нанайцы + китайцы

5. **[Ороки](http://localhost:3000/oroki)** (Сахалин) — 2498 чел. (2021)
   - Самоназвания: ульта, улта, орочун, орокил… (>20)
   - Медвежий праздник «чопо»
   - Музыкальная одежда — женские халаты с подвесками

## 🛠 Технологии

- **Next.js 16** — фреймворк для React
- **TypeScript** — типизация кода
- **SCSS Modules** — модульные стили
- **Tailwind CSS** — утиитарные классы
- **Anime.js** — анимации

## 🚀 Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
