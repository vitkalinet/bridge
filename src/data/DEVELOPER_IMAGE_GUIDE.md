/**
 * РУКОВОДСТВО ПО ДОБАВЛЕНИЮ ИЗОБРАЖЕНИЙ ДЛЯ СТРАНИЦ НАРОДОВ
 * ==========================================================
 * 
 * 1. СТРУКТУРА ПАПOK
 * -------------------
 * Все изображения хранятся в папке: public/images/gallery/
 * 
 * Для каждого народа создана отдельная папка:
 * - public/images/gallery/kereki/
 * - public/images/gallery/chamalaly/
 * - public/images/gallery/vod/
 * - public/images/gallery/tazy/
 * - public/images/gallery/oroki/
 * 
 * 2. ИМЕНОВАНИЕ ФАЙЛОВ
 * ---------------------
 * Формат: {Nation}_{Section}{Index}.{ext}
 * 
 * Где:
 * - {Nation} — ID народа (kereki, chamalaly, vod, tazy, oroki)
 * - {Section} — Код раздела (см. таблицу ниже)
 * - {Index} — Порядковый номер картинки в разделе (1, 2, 3...)
 * - {ext} — Расширение файла (jpg, png, svg, webp)
 * 
 * 3. КОДЫ РАЗДЕЛОВ
 * -----------------
 * | Раздел                    | Код       | Пример имени файла          |
 * |---------------------------|-----------|----------------------------|
 * | География проживания      | Geog      | Chamalal_Geog1.jpg         |
 * | Язык и современное        | Lang      | Chamalal_Lang1.jpg         |
 * | положение                 |           |                             |
 * |---------------------------|-----------|----------------------------|
 * | Традиции и ремёсла        | Trad      | Chamalal_Trad1.jpg         |
 * |                           |           | Chamalal_Trad2.jpg         |
 * |---------------------------|-----------|----------------------------|
 * | Одежда (мужская)          | ClothM    | Chamalal_ClothM1.jpg       |
 * |---------------------------|-----------|----------------------------|
 * | Одежда (женская)          | ClothF    | Chamalal_ClothF1.jpg       |
 * |                           |           | Chamalal_ClothF2.jpg       |
 * |---------------------------|-----------|----------------------------|
 * | Жилище                    | Dwell     | Chamalal_Dwell1.jpg        |
 * |                           |           | Chamalal_Dwell2.jpg        |
 * |---------------------------|-----------|----------------------------|
 * | Верования                 | Belief    | Chamalal_Belief1.jpg       |
 * |                           |           | Chamalal_Belief2.jpg       |
 * |---------------------------|-----------|----------------------------|
 * 
 * 4. ПОДПИСИ К ИЗОБРАЖЕНИЯМ
 * -------------------------
 * Подписи хранятся в файле: src/data/imageCaptions.ts
 * 
 * Формат записи:
 * {
 *   nationId: {
 *     section: {
 *       imageIndex: "Текст подписи"
 *     }
 *   }
 * }
 * 
 * Пример:
 * {
 *   chamalaly: {
 *     geog: {
 *       1: "Высокогорный аул Риквани, Дагестан"
 *     },
 *     trad: {
 *       1: "Трёхэтажный каменный дом башенного типа"
 *     }
 *   }
 * }
 * 
 * 5. АВТОМАТИЧЕСКОЕ ОТОБРАЖЕНИЕ
 * -----------------------------
 * Компонент GallerySection автоматически:
 * - Находит все изображения по шаблону имени
 * - Отображает их в соответствующем разделе
 * - Добавляет подписи из imageCaptions.ts
 * 
 * 6. ВАЖНО
 * --------
 * - Если для раздела нет изображений — раздел отображается без картинок
 * - Можно добавлять любое количество изображений в раздел (просто увеличивайте индекс)
 * - Подписи необязательны — если подписи нет, изображение показывается без неё
 * 
 * 7. ПРИМЕРЫ
 * ----------
 * Добавить 2 фото в раздел "География" для Чамалалов:
 * 1. Сохраните файлы: public/images/gallery/chamalaly/Chamalal_Geog1.jpg
 *                     public/images/gallery/chamalaly/Chamalal_Geog2.jpg
 * 2. Добавьте подписи в src/data/imageCaptions.ts:
 *    chamalaly: { geog: { 1: "Описание 1", 2: "Описание 2" } }
 * 
 * Добавить фото женской одежды для Води:
 * 1. Сохраните файл: public/images/gallery/vod/Vod_ClothF1.jpg
 * 2. Добавьте подпись: vod: { clothF: { 1: "Традиционный костюм" } }
 */
