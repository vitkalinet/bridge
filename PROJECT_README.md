# Голоса Земли — Малые народы России

Переписанная версия проекта на **Next.js 16** с использованием:
- **TypeScript**
- **Tailwind CSS** v4
- **SCSS Modules** для изолированных стилей компонентов
- **Anime.js** для красивых анимаций
- **Google Fonts**: Cormorant Garamond, Geologica, Unbounded

## Быстрый старт

### 1. Установите зависимости

```bash
npm install
```

Или запустите скрипт:
```bash
node install-deps.js
```

### 2. Запустите разработочный сервер

```bash
npm run dev
```

Откройте http://localhost:3000 в браузере.

### 3. Сборка для продакшена

```bash
npm run build
npm run start
```

## Особенности реализации

### Анимации (Anime.js)
- Плавное появление элементов при загрузке
- Пульсирующие орбы в hero секции
- Парящий символ в заголовке
- Stagger-анимация карточек
- Анимация модального окна при открытии/закрытии
- Интерактивные эффекты при наведении

### SCSS Modules
- Изолированные стили для каждого компонента
- CSS переменные для цветов и темизации
- Адаптивные медиа-запросы

### Tailwind CSS
- Утилитарные классы для базовой верстки
- Интеграция с SCSS для сложных компонентов

### Шрифты
- **Unbounded** — заголовки (современный, геометричный)
- **Geologica** — основной текст (читабельный гротеск)
- **Cormorant Garamond** — акцентный текст (элегантная антиква)

## Цветовая палитра

```scss
--bg: #0a0c0f;        // Основной фон
--bg2: #0f1318;       // Фон карточек
--gold: #c9a84c;      // Золотой акцент
--gold2: #e8c97a;     // Светлое золото
--teal: #2d7a7a;      // Бирюзовый
--teal2: #4da8a8;     // Светлая бирюза
--text: #e8e0d4;      // Основной текст
--text2: #a09888;     // Вторичный текст
```
